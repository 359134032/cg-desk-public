# 0.1.13：默认开启分辨率实验，清理旧增强代码

新配置默认选择当前显示器能容纳的最高 4:3 档位，最大 1600×1200。旧版保存的默认关闭值迁移一次，已有有效手选档位保留；本版手动选择关闭后，重启继续保持关闭。自动模式随显示器变化重新计算，宽、高都不超屏幕。

默认开启保留风险提示及启动前确认，确认默认仍为「否」。独立组件只改运行内存，不改写原 EXE 或资源；无法保证不被检测或账号安全。1600×1200 原生上限和再次调整窗口时的 FSR 等比显示保留。

发布前回归还发现首次缩小时，采集源过早移到屏幕边缘可能持续产生黑帧。现在先在屏幕内建立采集表面，收到三帧后再移到边缘，保留原生绘制尺寸和坐标映射。

删除旧增强注入器、代理构建器和旧增强服务；删除已确认无改善的资源半径补丁、诊断状态及专用测试；删除旧固定档位部署脚本和一次性进程探测工程。移除已无用途的档位禁用分支和锐化设置入口。保留当前地图缓存、UI 黑线修复、FSR 与有效的构建和回归工具。

之前 0.1.12 的本机人工验收报告为「效果一切正常」。本次清理删除未启用分支，仍需通过完整回归、原生组件检查及完整包验证；不把旧构建的人工报告当作新 DLL 的另一次实机验收。

发布前验证已完成：完整桌面回归 221 项；背景几何及 COM 接口检查 1524 项；地图缓存离线夹具 2666 场景、116233 项检查，均通过。系统 21 项导出转发及真实 Windows Direct3D7 RGB 设备在 1600×1200 的初始化、绘制和释放通过。FSR 检查包含真实 GPU 像素、首次缩小、输入映射、中文输入、失败回退、最小化恢复和客户端退出。源码及可达历史已按规则扫描。NuGet 漏洞源不可达产生 NU1900，代码编译无错误。

发布使用原客户端可信签名身份，附完整 Windows x64 自包含 ZIP、稳定清单和测试通道清单。私钥、游戏原始捕获和本地研究工件不入库或发布包。
