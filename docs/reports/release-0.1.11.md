# 0.1.11：启动分辨率与原生窗口适配

移除启动器内的 FSR、锐化界面、捕获后放大管线、旧增强代理和注入器，以及 Vortice/着色器依赖。保留原生窗口嵌入、输入法、光标恢复、多窗口预览、攻略与更新功能。

启动分辨率默认跟随游戏原生设置。实验档位启用前提示运行时调整仍可能被保护检测或被认定为外挂，确认默认选“否”。组件独立打包，只在显式启用时管理新增文件，原 EXE 和资源文件保持不变。恢复原生会核对自有新增文件后撤下；不同名、哈希不符和运行中的客户端会阻止替换。

档位按窗口台当前显示器宽高筛选；换屏、显示设置变化、打开列表及启动前重新校验。当前开放九个常见档位，最高横向尺寸 1366×768，也支持 1152×864 等比例。地图缓存边界以外的档位（包括 1920×1080）显示为暂未适配，禁止选择。未声称已完成所有主流屏幕的原生视口适配。

游戏出现后按实际客户区调整窗口台，计算周围控件所需空间，并限制在当前显示器工作区；不会通过 FSR 或拉伸冒充更大地图。空间不足时保留滚动查看。服务器角色下发范围保持不变，资源半径试验仍关闭。
