# 0.1.9 缩放屏幕下的鼠标坐标

150% 缩放时，窗口台按游戏自己的 800×600 摆放采集源，画面可以进入主区域。点击坐标仍按逻辑尺寸发出。Windows 把来自每显示器感知进程的鼠标消息送进 DPI 不感知的游戏时，会再按缩放比缩小一次，点击落在偏左上的位置。

现在按游戏窗口的实际像素换算点击，再交给系统缩放到游戏坐标。100% 缩放下两边尺寸相同，行为不变。

回归包含原有 FSR 点击检查，以及 150% 缩放下把画面中心点送进 DPI 不感知窗口后落在客户区中心的检查。
