# 魔力窗口台 0.1.16

修复点击工具栏后再点击 FSR 缩放画面，Home 等游戏快捷键可能失效的问题。左键、右键和双击现在会把键盘输入交回当前游戏。原尺寸模式下，点击游戏时由嵌入的游戏窗口接收键盘输入，避免窗口台与游戏反复争夺焦点导致标题栏闪烁。

Windows 桌面回归共通过 237 项。在独立测试客户端上，原尺寸和 FSR 模式都收到了通过系统输入发送的 Home，连续点击期间窗口台标题栏收到的停用消息均为零。另已验证中文输入、切换客户端及缩放失败后的恢复。旧版 0.1.15 在相同的 FSR 测试中可复现焦点丢失。实际游戏中的表现仍待玩家复验。

## 下载与升级

下载 `CgDesk-0.1.16-win-x64.zip` 并完整解压到新目录。退出旧窗口台后，运行新目录中的 `CgDesk.exe`，已有设置会自动载入。
