# 0.1.7 首发验收说明

日期：2026-10-27。此版本是 cg-desk-public 的首个公开 Release；代码从当前工作版本导出为独立初始提交，不包含旧仓库历史、发布备份、个人设置或签名私钥。

继承已验证的多窗口管理、原生嵌入、FSR、攻略、深浅色、鼠标恢复与签名更新功能。攻略不再有重复的分类下拉框；分类在百科页面中切换，搜索跟随当前分类。

普通界面为一个主画面和右侧单列滚动预览；迷你控制台为换行网格。曾用 4、8、12、20 个独立 800×600 测试窗口验证滚动、切换、FSR、迷你恢复和资源释放。测试尺寸下 20 窗口约维护 4 个可见 DWM 预览，屏幕外缩略图注销，不越过视口。

本次新增官方公开源默认值、旧地址迁移和自定义源保留检查，完整桌面回归 150 项通过。发布前执行当前源码、独立历史及最终 ZIP 的隐私规则扫描，签名清单用客户端内置公钥验签。正式发布后另做匿名 API、附件下载与客户端更新检测验证。

验证范围为当前 Windows x64 图形桌面；真实游戏多账号压力、其他系统、显卡和实际跨屏 DPI 未完成完整实机矩阵。FSR 回归使用实际窗口采集、GPU 输出像素读回和输入转发；独立测试窗口不能代替真实游戏性能。

更新默认指向公开 Releases，国内访问可自行配置备用镜像；尚未部署独立 CDN，不保证国内各运营商的下载表现。安装仍为用户手动解压，更新不自动关闭游戏或替换运行文件。

隐私扫描是限定规则验证，不保证检测所有形式的隐私；不包含对第三方运行时与 dgVoodoo 的完整内部审计。包内保留运行时通知及第三方许可，FSR 许可见原始头文件。

依赖恢复使用了本机缓存包；NuGet 在线漏洞数据源不可达（NU1900），本次没有完成在线依赖漏洞数据库检查。
