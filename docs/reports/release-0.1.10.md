# 0.1.10 画质增强下的中文输入

日期：2026-11-05。

修复开启画质增强后，游戏聊天框可以输入英文却无法完成中文组词和提交的问题。增强区域现在获得原生输入焦点，由宿主处理输入法组词，确认后的文字通过 Unicode 消息交给游戏，并由 Windows 转换到旧式 ANSI 窗口使用的编码。选字回车不会作为普通游戏按键转发；切换客户端时取消未确认的组词。

输入专项 12 项通过，完整桌面回归 175 项通过，包含实际 FSR 采集、GPU 像素、鼠标定位、功能键和向独立进程提交中文的检查。测试使用输入法消息模拟和独立测试窗口，尚未完成真实游戏配合具体中文输入法的人工验收。实现与测试边界见[输入修复说明](ime-fix-2026-11-05.md)。

发布物为 Windows x64 自包含 ZIP，保留 WebView2 安装器、第三方许可和使用说明。稳定、测试通道清单使用原发布密钥签名，客户端可信公钥不变。安装仍由用户手动解压，不自动关闭游戏或替换运行文件。

构建依赖使用本机缓存；NuGet 漏洞数据库不可达时会产生 NU1900 警告，编译无错误。源码、完整历史和最终 ZIP 按仓库规则进行限定隐私扫描，不代表完整第三方组件审计。
