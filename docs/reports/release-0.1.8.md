# 0.1.8 更新检查 403 修复

2026-10-27 实际匿名响应为 HTTP 403，`X-RateLimit-Remaining: 0`，属于 GitHub REST API 限流。0.1.7 将所有 403 统一提示为「请检查源是否公开可读」，造成误导。

稳定通道现把 GitHub Releases 地址转换为 `releases/latest/download/cgdesk-update-stable.json`，直接读取公开签名附件，不消耗 REST API 匿名额度。继续执行原有签名、通道、版本、架构和包摘要验证。

测试通道仍使用发布列表查找预发布版本，不将正式版检查冒充为测试版检查。依据限流和 Retry-After 响应头显示恢复时间，保存下次自动检查计划，并在恢复前阻止重复 API 请求；签名备用源仍会尝试。普通 401、403、404 分别说明授权、拒绝访问及发布/地址问题，不回显服务器正文中的网络地址。

完整回归 158 项通过，其中更新专项 56 项。涵盖稳定通道零 API 请求、测试版发现、限流信息与重试时间、重复点击退避、429、限流后的备用源，以及原有窗口、FSR、鼠标和主题检查。

在匿名 API 额度耗尽的实际网络环境中，新服务以原有官方仓库地址成功读取 0.1.7 签名清单，完成版本比较并验证已完整匿名下载的 ZIP 摘要。用户无需 GitHub 登录或 token。发布后另行核验 0.1.8 的实际清单和包。

该修复避开 REST API 配额，不保证 GitHub 附件在所有地区和网络可达；国内下载镜像仍可由发布者配置。安装依旧为手动解压，不自动关闭游戏或替换运行文件。依赖恢复的在线漏洞数据库不可达，未完成在线依赖漏洞扫描。
