# 0.1.15：修复大视口战斗入场与切屏时长

大于800×600时，战斗阵形改用原800×600逻辑布局居中，避免人物接近和返回的距离随画布放大。初始入场阶段仅裁掉原视口之外的走路段，保留共享entry/站位坐标与速度，不影响后续命令使用的目标。用户实测确认入场正常，无闪现或跳位；采样显示玩家约0.88秒、敌方约1.17秒，步长与更新节奏保持原值。

常见条带转场保留原函数单次调用，以画布比例补偿步长、加速度及独立阈值，避免大画布拉长进入战斗或传送的切屏。加速度量化为精确二进制分数，防止逆向效果因浮点残差无法收尾。用户确认切屏速度恢复正常。此前的转场缓冲区、UI接缝和地图缓存修复继续保留。

4:3、默认开启、1600×1200上限、按屏幕筛选、风险确认和窗口FSR缩放保持原行为。原EXE和资源文件不写入。不改变地图移动速度、全局时钟或通信协议。Home与标题栏经用户后续确认正常，相关输入路径没有新增改动。

地图行走疑似加速经测速未见持续倍速；本机高分辨率地图主要耗时在原始Draw调用，低帧率会让位置成批跳动。设置和说明补充性能提示，可降低启动档位再FSR放大。GPU兼容层虽在独立测试中更快，但真实游戏画面模糊，最近点对照仍无改善，已完整撤回，不随包提供。外围NPC/路灯靠近才出现仍是已知限制，不包含提前刷新或队列扩容。

清理了未采用的FSR生命周期草稿、GPU试验代码和高频运动/绘制计时采样，正式包保留原已验证的FSR实现。试验原始记录和源稿仅在本地归档，不进入源码或附件。

验证：4755项战斗几何、初始演员坐标、ABI及组合回退检查；586项转场速度检查、5项权限双失败检查；1524项接缝/COM检查；21个系统导出及非目标保护检查；1600×1200真实系统RGB设备创建、绘制与释放；正常Windows桌面223项完整回归，包含FSR实际像素、4:3缩放、鼠标、中文输入及退出恢复。权限恢复失败时组件明确报告不健康，不将部分回退误报为成功。源码隐私规则扫描通过。NuGet漏洞数据源不可达产生NU1900告警，编译无错误。覆盖范围为已核对客户端、本机普通战斗及常用转场，不能代替所有技能、地图或硬件的实机矩阵。
